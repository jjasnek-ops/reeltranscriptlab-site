AI and agent access

Reel Transcript Lab turns a public Instagram Reel or video post into text in a browser. This page documents the public, read-only guide lookup available to agents.

What is available

  • Search and read the five public guides currently linked from the guide index.
  • Use the site’s existing Instagram transcript tool directly in a browser. Transcription is a separate user-facing action and is not exposed through the agent lookup API or MCP tools.
  • Read the OpenAPI description, call the MCP endpoint, or follow the Agent Skills index.

Guide lookup

GET /api/agent/guides?q=timing searches guide titles, summaries, and stable slugs. GET /api/agent/guides/{slug} returns one known public guide. The API accepts no arbitrary URL, private content, transcript request, identity data, or write operation.

Limits and authentication

Guide lookup is public and read-only. No sign-in is required. OAuth registration and credential issuance are under construction and unavailable; agents must not attempt those operations. The public transcript tool remains separate and may be unavailable when its provider has no capacity.

How agents should answer

Use the guide’s canonical URL as the source. Preserve exact identifiers and stated limits, answer in the visitor’s language, and give concrete next steps. If the public pages do not establish a fact, say that it is unknown.
